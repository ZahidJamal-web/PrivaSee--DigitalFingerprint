# 🛡️ Digital Fingerprint Dashboard & Terminal Console

An advanced, production-ready web telemetry profiling suite designed to visualize how explicit tracking data matrices can be collected by modern web applications without relying on traditional storage cookies. 

This educational platform categorizes low-level browser characteristics, system environment setups, canvas-rasterized cryptographic tracking strings, and real-time geographic spatial location metrics into a high-utility glassmorphic layout dashboard interface combined with an interactive retro terminal console shell emulator.

## Purpose

The purpose of this project is to raise awareness about the risks of online privacy and educate users about the data that can be collected by websites. The website provides a visual representation of the types of data that websites can collect, and aims to encourage users to exercise caution when visiting unknown or unsafe websites.

## 🔧 Installation & Deployment

Modern web browsers enforce strict security rules that block background geolocation network lookups and cross-origin mapping tiles if you run scripts directly from your storage directories using raw `file:///` protocols. To access all modules, you **must run the platform over a local network server loop**.

### Option 1: Visual Studio Code (Recommended)
1. Open the project root workspace directory in **VS Code**.
2. Navigate to the extensions market tab (`Ctrl+Shift+X`), look for **Live Server**, and install it.
3. Open `index.html` and click on the **Go Live** button at the bottom-right status bar.
4. Your browser will automatically open the project at `http://127.0.0.1:5500`.

### Option 2: Python HTTP Server (Terminal CLI)
If you prefer running a command shell directly from your project folder:
```bash
# For Python 3.x installations
python -m http.server 8000
```
Then launch your browser navigation path bar straight to `http://localhost:8000`.

## 💻 Available Terminal Directives

Once the simulated boot loader sequence achieves 100% telemetry initialization inside your console section box, click inside the active prompt row to interface directly with these custom engine parameters:

* `help` - Renders an instructional shell syntax documentation map listing out all interactive platform inputs.
* `df` - Prints a clean operational synopsis detailing tracking vectors, fingerprint generation methodologies, and user identification techniques.
* `diagnose` - Triggers a complete runtime data scanner sweep, refreshing data parameters, network variables, and redrawing mapping layouts.
* `clear` - Wipes all system history lines from the terminal screen to reset the console view window cleanly.
